🛠 Step-by-Step Setup Guide

Follow these exact steps. Don't skip. Each step builds on the previous.

  1. 1
    Install Git — Go to git-scm.com/downloads, download for your OS (Windows/Mac/Linux). Run installer with default settings.
  2. 2
    Verify Installation — Open terminal/cmd and run git --version. You should see something like git version 2.43.0.
  3. 3
    Configure Identity — Run git config --global user.name "Your Name" and git config --global user.email "you@email.com".
  4. 4
    Create GitHub Account — Visit github.com, sign up. Choose a professional username — recruiters will see this.
  5. 5
    Setup SSH Key — Run ssh-keygen -t ed25519 -C "your@email.com", then add public key to GitHub Settings → SSH Keys.
  6. 6
    Create Your First Repo — On GitHub, click "New Repository". Name it careerwizard-internship. Initialize with README.
  7. 7
    Clone + First Commit — git clone [your-repo-url], create a file, then git add . → git commit -m "Day 1: setup" → git push.
  8. 8
    Practice Branching — Create a feature branch: git checkout -b feature/test, make changes, then merge back to main.
