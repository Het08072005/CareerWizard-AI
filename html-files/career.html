Today — Day 6: JWT Authentication
🔐 What is JWT?
Auth Intermediate
📖 Definition
JWT (JSON Web Token) is a compact, URL-safe means of representing claims to be transferred between two parties. It consists of three parts: Header, Payload, and Signature, separated by dots.
⚙️ How it works
1. User logs in → server validates credentials
2. Server creates JWT signed with a secret key
3. Client stores JWT (localStorage/cookie)
4. Client sends JWT in Authorization: Bearer <token> header
5. Server verifies signature → grants access
💻 Code Example
// Generate JWT token
const jwt = require('jsonwebtoken');

const generateToken = (userId) => {
  return jwt.sign(
    { id: userId },
    process.env.JWT_SECRET,
    { expiresIn: '7d' }
  );
};

// Verify JWT middleware
const authMiddleware = (req, res, next) => {
  const token = req.headers.authorization?.split(' ')[1];
  if (!token) return res.status(401).json({ error: 'No token' });
  try {
    req.user = jwt.verify(token, process.env.JWT_SECRET);
    next();
  } catch { res.status(401).json({ error: 'Invalid token' }); }
};

💡 Pro Tip

Always use short expiry for access tokens (15min) and a separate refresh token (7 days) stored in httpOnly cookies. Never store access tokens in localStorage for sensitive apps.

⚠️ Common Mistake

Don't store sensitive data (passwords, credit card info) in the JWT payload — it's only base64 encoded, not encrypted. Anyone can decode it.
