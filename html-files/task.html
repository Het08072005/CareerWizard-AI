Complete Syntax Reference
📝 Basic Markdown
# Title→ H1 heading (Page/Day title)
## Title→ H2 section heading
### Title→ H3 sub-heading
Normal text→ Paragraph
**bold**→ Bold text
*italic*→ Italic / green accent
`code`→ Inline code
---→ Horizontal divider
🎯 Special Blocks (:::block … :::)
:::concept→ Blue concept explanation box
:::analogy→ Amber analogy box. First line = emoji, second = title
:::image→ Image. url: link, caption: text, alt: text
:::video→ Video player. url:, title:, duration:, required: true/false
:::code python→ Code block. Language after :::code. First ### line = title
:::tip→ Green tip callout. First ### = label
:::warning→ Amber warning callout
:::important→ Blue important callout
:::keypoints→ Purple key points. First ### = title, - items = points
:::quiz→ Interactive quiz. Q:, A:, B:, C:, D:, CORRECT:, EXPLAIN:
:::task-hero→ Task day dark hero. #=task prefix, ##=title, body=desc
:::requirements→ 3-level req box. ### BEGINNER / INTERMEDIATE / ADVANCED sections
:::checklist→ Pre-submit checklist. - Item one - Item two
:::scoring→ AI scoring grid. SCORE: label|val|max, PASS: label|val|max
:::submit→ GitHub submit box
:::wyl→ "What you'll learn" grid. - Item one - Item two
